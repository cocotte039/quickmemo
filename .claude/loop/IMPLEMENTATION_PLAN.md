# 実装計画 (Implementation Plan)

## プロジェクト概要

- 目的: 音声入力の基本品質を向上させる（バグ修正 + 操作性改善）
- スコープ: テキスト重複修正、停止ボタンレスポンス改善、録音安定性向上、追記モード発見性向上
- 非目標: 新機能追加（言語切替、音声録音保存、プロンプトカスタマイズ、セグメントアニメーション等）

## 完了基準 (Definition of Done)

- [ ] 全タスクが実装済み
- [ ] 手動テスト6シナリオがすべてパス:
  1. 短い録音（5秒）→ 停止 → テキスト確認
  2. 1分以上の録音（auto-restart を跨ぐ）→ 停止 → 重複なし確認
  3. 録音中にキャンセル → 次の録音が正常に開始されること
  4. 追記モードでの録音 → テキストが正しく追記されること
  5. 新規メモモードでの録音 → Gemini 要約が正常に動作すること
  6. 録音中の沈黙（10秒以上）→ auto-restart が正常に動作すること
- [ ] Chrome DevTools Console でエラーがないこと
- [ ] Service Worker のキャッシュバージョンが更新されていること

# T1.2: auto-restart のインスタンス管理改善（テキスト重複の根本修正）

## 目的

Web Speech API の auto-restart 時に、旧インスタンスからの遅延結果が混入してテキストが重複する問題を根本的に解決する。generation（世代番号）方式で、現在のアクティブインスタンスからの結果のみを受け入れる。

## 変更対象

| ファイル | 変更概要 |
|---|---|
| `app.js` | `createWebSpeechSTT` 内に generation 変数を追加、onresult にガード追加、auto-restart 時に旧インスタンスを abort |

## 詳細仕様

### 1. generation 変数の追加

`createWebSpeechSTT` 関数のクロージャスコープに `generation` 変数を追加する。

```javascript
// app.js:167 createWebSpeechSTT 関数内
function createWebSpeechSTT(lang) {
  const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
  if (!SpeechRecognition) return null;

  let recognition = null;
  let callbacks = { onResult: null, onError: null, onEnd: null };
  let generation = 0;  // ← 追加

  function createRecognition() {
    generation++;                    // ← 追加
    const myGen = generation;        // ← 追加（クロージャキャプチャ）
    const rec = new SpeechRecognition();
    rec.lang = lang;
    rec.continuous = true;
    rec.interimResults = true;
    let processedFinalCount = 0;

    rec.onresult = (event) => {
      if (myGen !== generation) return;  // ← 追加: 旧世代の結果を無視
      // ... 既存のループ処理 ...
    };
    // ...
  }
}
```

### 2. auto-restart 時の旧インスタンス abort

```javascript
// app.js:200-209 の onend 内 auto-restart 部分
rec.onend = () => {
  if (voiceState.recording) {
    rec.onresult = null;
    rec.onerror = null;
    rec.onend = null;
    try { rec.abort(); } catch (e) { /* ignore */ }  // ← 追加: 旧インスタンスを確実に停止
    recognition = createRecognition();
    try { recognition.start(); } catch (e) { /* ignore */ }
    return;
  }
  if (callbacks.onEnd) callbacks.onEnd();
};
```

### 3. onResult コールバック（startVoiceMemo/startVoiceAppend 内）にガード追加

```javascript
// app.js:1454-1464 の engine.onResult
engine.onResult = (text, isFinal) => {
  if (voiceState.cancelled) return;
  if (!voiceState.recording && isFinal) return;  // ← 追加: 停止後の遅延 final result を無視
  if (isFinal) {
    // ... 既存の dedup + push ...
  }
  renderTranscript(text, isFinal);
};
```

同様の変更を `startVoiceAppend` 内の `engine.onResult` にも適用する。

## 受入条件

- [ ] 1分以上の録音（auto-restart を跨ぐ）でテキストが重複しないこと
- [ ] 沈黙→再発話の繰り返しで重複が起きないこと
- [ ] auto-restart の前後でテキストの欠損が起きないこと

## テスト方針

- 手動テスト: Chrome で1分以上録音し、途中で10秒程度の沈黙を挟む
- Chrome DevTools Console で generation のインクリメントを確認（一時的に console.log 追加）
- 沈黙→再発話を3回繰り返し、重複テキストが表示されないことを確認

## 依存関係

- 前提: T1.1（processVoiceResult の二重呼び出し防止）
- 並行可能: T1.3（dedup ロジック強化）

## 注意事項

- `rec.abort()` は Chrome で `onerror` (error='aborted') を発火するが、app.js:196 で `event.error === 'aborted'` は無視されている。問題なし。
- `abort()` が `onend` を発火する場合、既に `rec.onend = null` で解除されているため影響なし。
- generation チェックは `onresult` 内のみで十分。`onerror` や `onend` は既にハンドラ null 化で対処済み。

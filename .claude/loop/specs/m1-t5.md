# T1.5: auto-restart のエラーハンドリング改善

## 目的

auto-restart 時の `recognition.start()` がエラーになった場合の処理を改善する。現在はエラーを握りつぶしている（`catch (e) { /* ignore */ }`）ため、録音が無言で停止する場合がある。

## 変更対象

| ファイル | 変更概要 |
|---|---|
| `app.js` | `createWebSpeechSTT` 内の auto-restart エラーハンドリングを改善 |

## 詳細仕様

### 1. リトライカウンタの追加

`createWebSpeechSTT` のクロージャスコープにリトライカウンタを追加する。

```javascript
function createWebSpeechSTT(lang) {
  // ... 既存 ...
  let generation = 0;
  let restartRetryCount = 0;     // ← 追加
  const MAX_RESTART_RETRIES = 3; // ← 追加
  // ...
}
```

### 2. auto-restart のエラーハンドリング改善

現在のコード（app.js:200-209）の auto-restart 部分を改修:

```javascript
rec.onend = () => {
  if (voiceState.recording) {
    rec.onresult = null;
    rec.onerror = null;
    rec.onend = null;
    try { rec.abort(); } catch (e) { /* ignore */ }
    recognition = createRecognition();

    try {
      recognition.start();
      restartRetryCount = 0; // 成功したらリセット
    } catch (e) {
      restartRetryCount++;
      if (restartRetryCount >= MAX_RESTART_RETRIES) {
        // リトライ上限到達: graceful stop
        voiceState.recording = false;
        if (callbacks.onEnd) callbacks.onEnd();
        return;
      }
      if (e.name === 'InvalidStateError') {
        // ブラウザがまだ前のインスタンスを処理中。少し待ってリトライ
        setTimeout(() => {
          if (!voiceState.recording) return;
          recognition = createRecognition();
          try {
            recognition.start();
            restartRetryCount = 0;
          } catch (e2) {
            // リトライも失敗: graceful stop
            voiceState.recording = false;
            if (callbacks.onEnd) callbacks.onEnd();
          }
        }, 300);
      } else if (e.name === 'NotAllowedError') {
        // マイク権限が取り消された
        voiceState.recording = false;
        if (callbacks.onError) callbacks.onError('microphone-denied');
        if (callbacks.onEnd) callbacks.onEnd();
      } else {
        // その他のエラー: 1回リトライ
        setTimeout(() => {
          if (!voiceState.recording) return;
          recognition = createRecognition();
          try {
            recognition.start();
            restartRetryCount = 0;
          } catch (e2) {
            voiceState.recording = false;
            if (callbacks.onEnd) callbacks.onEnd();
          }
        }, 300);
      }
    }
    return;
  }
  if (callbacks.onEnd) callbacks.onEnd();
};
```

### 3. graceful stop の結果

graceful stop 時は:
- `voiceState.recording = false` に設定
- `callbacks.onEnd()` が呼ばれる
- → `processVoiceResult()` が呼ばれる
- → それまでに蓄積されたテキストで結果を処理（新規メモ or 追記）
- ユーザーは「録音が途中で終了した」ことになるが、テキストは失われない

## 受入条件

- [ ] auto-restart のエラーが握りつぶされないこと
- [ ] InvalidStateError で300ms後にリトライされること
- [ ] 3回リトライ失敗後に graceful stop すること
- [ ] graceful stop 後、それまでのテキストが保存されること
- [ ] 正常な auto-restart（エラーなし）の動作が変わらないこと

## テスト方針

- 手動テスト: 1分以上の録音で auto-restart が正常に動作することを確認
- Console で `restartRetryCount` の値を確認（通常は 0 のまま）
- エラーケースの再現は困難だが、リトライ上限後の graceful stop は `recognition.start()` を一時的に失敗させるモックで確認可能

## 依存関係

- 前提: T1.2（インスタンス管理改善）— generation 変数が先に導入されている前提

## 注意事項

- リトライの300ms は安全マージン。短すぎると Chrome が `InvalidStateError` を返す。
- `restartRetryCount` はクロージャスコープ。auto-restart が成功するたびに 0 にリセットされるので、「連続失敗のみ」をカウントする。
- `NotAllowedError` はマイク権限が取り消された場合に発生。この場合はリトライせず、ユーザーに通知する。
- `setTimeout` を使うため、300ms 間は録音が途切れる。ただし現在も auto-restart の瞬間は途切れているため、体感的な差は最小限。

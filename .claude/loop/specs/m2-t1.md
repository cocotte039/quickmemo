# T2.1: 追記モードの発見性改善

## 目的

エディタヘッダーの音声追記ボタンが「追記機能」であることをユーザーが直感的に認識できるようにする。現在のマイクアイコンはリスト画面の新規音声メモ FAB と同一デザインで、区別がつかない。

## 変更対象

| ファイル | 変更概要 |
|---|---|
| `index.html` | voice-append-btn の SVG を「マイク+プラス」アイコンに変更、title 属性追加 |
| `style.css` | ボタンのアクセント輪郭スタイル、初回ツールチップの CSS |
| `app.js` | 初回表示フラグ管理（localStorage） |

## 詳細仕様

### 1. アイコンの差別化（index.html:91-98）

現在のマイクアイコン SVG を、マイクに小さな「+」マークを重ねたデザインに変更する。

```html
<button id="voice-append-btn" class="header__action header__voice-append" aria-label="Voice append" title="音声で追記">
  <svg width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <rect x="9" y="1" width="6" height="11" rx="3"/>
    <path d="M19 10v1a7 7 0 01-14 0v-1"/>
    <line x1="12" y1="19" x2="12" y2="23"/>
    <line x1="8" y1="23" x2="16" y2="23"/>
    <!-- + マーク（右上に小さく配置） -->
    <circle cx="19" cy="5" r="4" fill="var(--bg-primary, #0d1117)" stroke="currentColor" stroke-width="1.5"/>
    <line x1="17" y1="5" x2="21" y2="5" stroke-width="1.5"/>
    <line x1="19" y1="3" x2="19" y2="7" stroke-width="1.5"/>
  </svg>
</button>
```

### 2. ボタンスタイル（style.css）

```css
.header__voice-append {
```

### 3. 初回ツールチップ（CSS + JS）

CSS で pseudo-element ベースのツールチップを定義:

```css
.header__voice-append[data-tooltip]::after {
  content: attr(data-tooltip);
  position: absolute;
  top: 100%;
  left: 50%;
  transform: translateX(-50%);
  background: var(--bg-surface);
  color: var(--text-primary);
  padding: 0.25rem 0.5rem;
  border-radius: 0.25rem;
  font-size: 0.75rem;
  white-space: nowrap;
  pointer-events: none;
  opacity: 1;
  transition: opacity 0.3s;
  z-index: 10;
}
```

JS で初回表示管理:
```javascript
// openEditor() 内で、初回のみ data-tooltip を設定
const TOOLTIP_KEY = 'quickmemo_voice_append_shown';
if (!localStorage.getItem(TOOLTIP_KEY)) {
  voiceAppendBtn.setAttribute('data-tooltip', '🎤 音声で追記できます');
  setTimeout(() => {
    voiceAppendBtn.removeAttribute('data-tooltip');
    localStorage.setItem(TOOLTIP_KEY, '1');
  }, 3000);
}
```

## 受入条件

- [ ] エディタヘッダーのマイクボタンが「+」付きアイコンに変更されていること
- [ ] ボタンにアクセントカラーの輪郭が表示されること
- [ ] 初回エディタ表示時にツールチップが3秒間表示されること
- [ ] 2回目以降はツールチップが表示されないこと
- [ ] ボタンタップで音声追記が正常に開始されること

## テスト方針

- 手動テスト: 新しいブラウザプロファイル（または localStorage クリア後）でエディタを開き、ツールチップが表示されることを確認
- 手動テスト: ツールチップ表示後にエディタを閉じて再度開き、ツールチップが非表示であることを確認
- 手動テスト: ボタンタップで追記モードの録音が開始されることを確認

## 依存関係

- 前提: M1（Phase 1）の全タスクが完了していること
- 並行可能: T2.2, T2.3

## 注意事項

- SVG 内の `fill="var(--bg-primary, #0d1117)"` は CSS 変数を使用。SVG 内の CSS 変数は `<svg>` がインラインの場合のみ有効（外部 SVG ファイルでは不可）。index.html 内のインライン SVG なので問題なし。
- ツールチップの CSS `position: absolute` は mobile Safari で `overflow: hidden` な親要素内では切れる可能性がある。ヘッダーの `overflow` 設定を確認すること。
- `title` 属性はモバイルでは長押し時のみ表示されるため、初回ツールチップが主要な発見手段になる。

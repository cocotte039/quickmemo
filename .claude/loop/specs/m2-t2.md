# T2.2: 録音経過時間カウンター

## 目的

録音中に経過時間（00:00 形式）を表示し、録音が正常に進行していることをユーザーに伝える。これにより「録音が動いているのか不安」という問題を緩和する。

## 変更対象

| ファイル | 変更概要 |
|---|---|
| `app.js` | voiceState に timerInterval 追加、タイマー表示ロジック、全完了パスでのクリア処理 |

## 詳細仕様

### 1. voiceState にタイマー関連プロパティを追加

```javascript
const voiceState = {
  // ... 既存プロパティ ...
  timerInterval: null,  // ← 追加
  timerStart: null,     // ← 追加
};
```

### 2. resetVoiceState にクリア処理を追加

```javascript
function resetVoiceState() {
  // ... 既存リセット ...
  if (voiceState.timerInterval) {
    clearInterval(voiceState.timerInterval);
  }
  voiceState.timerInterval = null;
  voiceState.timerStart = null;
}
```

### 3. タイマー開始（startVoiceMemo / startVoiceAppend 共通）

`engine.start()` の直前に追加:

```javascript
// タイマー開始
voiceState.timerStart = Date.now();
voiceState.timerInterval = setInterval(() => {
  const elapsed = Math.floor((Date.now() - voiceState.timerStart) / 1000);
  const min = String(Math.floor(elapsed / 60)).padStart(2, '0');
  const sec = String(elapsed % 60).padStart(2, '0');
  const baseLabel = voiceState.appendMode ? 'Appending...' : 'Recording...';
  voiceStatusLabel.textContent = `${baseLabel} ${min}:${sec}`;
}, 1000);
```

### 4. タイマー停止

以下の全箇所で `clearInterval` を実行する:
- `stopVoiceMemo()`: 即時停止
- `cancelVoiceMemo()`: 即時停止
- `resetVoiceState()`: フォールバック（他で漏れた場合のセーフティネット）

`stopVoiceMemo()` への追加:
```javascript
function stopVoiceMemo() {
  voiceState.recording = false;
  if (voiceState.timerInterval) {
    clearInterval(voiceState.timerInterval);
    voiceState.timerInterval = null;
  }
  // ... 残りの既存コード ...
}
```

`cancelVoiceMemo()` への追加:
```javascript
function cancelVoiceMemo() {
  // ... 既存の先頭部分 ...
  if (voiceState.timerInterval) {
    clearInterval(voiceState.timerInterval);
    voiceState.timerInterval = null;
  }
  // ... 残り ...
}
```

## 受入条件

- [ ] 録音中に「Recording... 00:12」形式で経過時間が表示されること
- [ ] 追記モードでは「Appending... 00:12」形式で表示されること
- [ ] 1秒ごとに更新されること
- [ ] 停止ボタン押下後にタイマーが止まること
- [ ] キャンセル後にタイマーが止まること
- [ ] 次の録音で 00:00 からリスタートすること

## テスト方針

- 手動テスト: 録音開始→タイマーが動くことを確認→停止→タイマーが止まることを確認
- 手動テスト: キャンセル→タイマーが止まることを確認
- 手動テスト: 再度録音→00:00 からスタートすることを確認
- Chrome DevTools で `voiceState.timerInterval` が null であることを確認（タイマーリークなし）

## 依存関係

- 前提: M1（Phase 1）の全タスクが完了していること
- 並行可能: T2.1, T2.3

## 注意事項

- `setInterval` のタイマーリークが最大のリスク。`resetVoiceState()` でのクリアがセーフティネットとなる。
- `voiceStatusLabel.textContent` の直接書き換えは、stopVoiceMemo 内の「保存中...」への変更と競合しない（stopVoiceMemo でタイマーを先に停止するため）。

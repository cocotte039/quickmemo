# T2.3: 追記モードのオーバーレイ差別化

## 目的

追記モードのオーバーレイを新規メモモードと視覚的に差別化し、ユーザーが「今どちらのモードで録音しているか」を即座に認識できるようにする。

## 変更対象

| ファイル | 変更概要 |
|---|---|
| `app.js` | startVoiceAppend でオーバーレイにクラス付与、processVoiceResult/cancelVoiceMemo でクラス除去 |
| `style.css` | `--append` バリアントのスタイル定義 |

## 詳細仕様

### 1. オーバーレイへのクラス付与（app.js）

`startVoiceAppend()` 内の `voiceOverlay.hidden = false;` の前後に:
```javascript
voiceOverlay.classList.add('voice-overlay--append');
```

### 2. クラス除去（app.js）

以下の箇所で `voiceOverlay.classList.remove('voice-overlay--append');` を追加:
- `cancelVoiceMemo()` 内の `voiceOverlay.hidden = true;` の前
- `processVoiceResult()` 内の `voiceOverlay.hidden = true;` の前（追記モード完了時）
- または `resetVoiceState()` 内に統一的に配置

### 3. CSS スタイル（style.css）

```css
/* 追記モードのオーバーレイ差別化 */
.voice-overlay--append .voice-overlay__pulse {
  background: var(--accent);  /* 赤 → 青に変更 */
  box-shadow: 0 0 0 0 rgba(88, 166, 255, 0.5);
}

.voice-overlay--append .voice-overlay__label {
  color: var(--accent);
}

.voice-overlay--append .voice-overlay__context {
  font-size: 1rem;
  font-weight: 600;
  margin-bottom: 0.75rem;
  padding: 0.5rem 1rem;
  background: rgba(88, 166, 255, 0.1);
  border-radius: 0.375rem;
  border-left: 3px solid var(--accent);
}

.voice-overlay--append .voice-overlay__stop {
  background: var(--accent);  /* 赤 → 青 */
}

@keyframes pulse-accent {
  0% { box-shadow: 0 0 0 0 rgba(88, 166, 255, 0.5); }
  70% { box-shadow: 0 0 0 10px rgba(88, 166, 255, 0); }
  100% { box-shadow: 0 0 0 0 rgba(88, 166, 255, 0); }
}

.voice-overlay--append .voice-overlay__pulse {
  animation: pulse-accent 1.5s ease-in-out infinite;
}
```

### 4. コンテキスト表示の強化

現在の `voiceContext` テキスト（対象ノート名）は小さく目立たない。上記 CSS でフォントサイズ拡大 + 背景色 + 左ボーダーで目立たせる。

## 受入条件

- [ ] 追記モードのパルスアニメーションが青色であること
- [ ] 追記モードの停止ボタンが青色であること
- [ ] 追記モードのコンテキスト（対象ノート名）が目立つ表示であること
- [ ] 新規メモモードのオーバーレイは従来通り（赤色）であること
- [ ] オーバーレイ閉じた後に次の録音で正しい色に戻ること

## テスト方針

- 手動テスト: 新規メモの録音→赤色パルス確認→停止
- 手動テスト: エディタで追記ボタンタップ→青色パルス確認→停止
- 手動テスト: 追記→停止→リスト→新規録音→赤色に戻ることを確認

## 依存関係

- 前提: M1（Phase 1）の全タスクが完了していること
- 推奨: T2.1（追記モード発見性改善）と同時に実装

## 注意事項

- `@keyframes pulse-accent` は既存の `@keyframes pulse`（赤色版）と別名で定義する。
- `.voice-overlay--append` クラスの除去を `resetVoiceState()` で行う場合、`voiceOverlay` DOM 要素への参照が必要。グローバル変数 `voiceOverlay` は既に存在するので問題ない。

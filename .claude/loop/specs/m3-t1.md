# T3.1: オーバーレイのフェードアウトトランジション

## 目的

録音オーバーレイの表示/非表示を `hidden` 属性のトグルから `opacity` + `pointer-events` ベースのトランジションに変更し、閉じる際にフェードアウトアニメーションを追加する。

## 変更対象

| ファイル | 変更概要 |
|---|---|
| `style.css` | `.voice-overlay` のトランジション定義、`--visible` / `--hidden` 状態のスタイル |
| `app.js` | `voiceOverlay.hidden = true/false` を `classList` ベースの表示/非表示に変更 |

## 詳細仕様

### 1. CSS トランジション定義

```css
.voice-overlay {
  /* 既存スタイルに追加 */
  opacity: 0;
  pointer-events: none;
  transition: opacity 200ms ease-out;
}

.voice-overlay.voice-overlay--visible {
  opacity: 1;
  pointer-events: auto;
}
```

### 2. JS の表示/非表示ロジック変更

表示（`voiceOverlay.hidden = false` の全箇所）:
```javascript
voiceOverlay.hidden = false;  // display 復帰（hidden 属性を外す）
requestAnimationFrame(() => {
  voiceOverlay.classList.add('voice-overlay--visible');
});
```

非表示（`voiceOverlay.hidden = true` の全箇所）:
```javascript
voiceOverlay.classList.remove('voice-overlay--visible');
voiceOverlay.addEventListener('transitionend', function handler() {
  voiceOverlay.hidden = true;
  voiceOverlay.removeEventListener('transitionend', handler);
}, { once: true });
// フォールバック: transitionend が発火しない場合（prefers-reduced-motion 等）
setTimeout(() => { voiceOverlay.hidden = true; }, 300);
```

### 3. ヘルパー関数

影響箇所が5箇所以上あるため、ヘルパー関数を作成:

```javascript
function showVoiceOverlay() {
  voiceOverlay.hidden = false;
  requestAnimationFrame(() => {
    voiceOverlay.classList.add('voice-overlay--visible');
  });
}

function hideVoiceOverlay() {
  voiceOverlay.classList.remove('voice-overlay--visible');
  voiceOverlay.classList.remove('voice-overlay--append');
  const fallback = setTimeout(() => { voiceOverlay.hidden = true; }, 300);
  voiceOverlay.addEventListener('transitionend', () => {
    clearTimeout(fallback);
    voiceOverlay.hidden = true;
  }, { once: true });
}
```

## 受入条件

- [ ] オーバーレイが 200ms でフェードアウトすること
- [ ] フェードアウト中にオーバーレイの要素がクリックできないこと（pointer-events: none）
- [ ] `prefers-reduced-motion` 環境でも正常に非表示になること（フォールバック）
- [ ] 新規メモモード・追記モード・キャンセルの全パスでフェードアウトが動作すること

## テスト方針

- 手動テスト: 録音→停止→フェードアウトアニメーションを目視確認
- 手動テスト: キャンセル→フェードアウトを確認
- Chrome DevTools で `prefers-reduced-motion` をシミュレートし、フォールバックが動作することを確認

## 依存関係

- 前提: M1, M2 の全タスクが完了していること

## 注意事項

- `hidden` 属性は `display: none` を適用する。opacity トランジションは `display: none` からは動作しないため、表示時は `hidden` を外してから1フレーム後に `opacity: 1` を適用する必要がある（`requestAnimationFrame`）。
- 影響箇所が多い（overlay の hidden 操作が5箇所以上）ため、ヘルパー関数での一括管理が重要。

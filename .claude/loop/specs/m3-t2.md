# T3.2: ブラウザ互換性チェック

## 目的

Web Speech API 非対応ブラウザ（Firefox, Safari の一部バージョン）でのエラーメッセージを改善し、ユーザーに具体的な対応方法を案内する。

## 変更対象

| ファイル | 変更概要 |
|---|---|
| `app.js` | `getSTTEngine()` / `startVoiceMemo()` / `startVoiceAppend()` のエラーメッセージ改善 |

## 詳細仕様

### 1. ブラウザ判定ヘルパー

```javascript
function getSpeechSupportInfo() {
  const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
  if (SpeechRecognition) {
    return { supported: true };
  }
  // ブラウザ別のメッセージ
  const ua = navigator.userAgent;
  if (/Firefox/i.test(ua)) {
    return { supported: false, message: 'Voice input requires Chrome or Edge. Firefox does not support Web Speech API.' };
  }
  if (/Safari/i.test(ua) && !/Chrome/i.test(ua)) {
    return { supported: false, message: 'Voice input requires Chrome or Edge. Safari has limited Web Speech API support.' };
  }
  return { supported: false, message: 'Voice input is not supported in this browser. Please use Chrome or Edge.' };
}
```

### 2. エラーメッセージの更新

`startVoiceMemo()` (app.js:1430-1435):
```javascript
const engine = getSTTEngine();
if (!engine) {
  const info = getSpeechSupportInfo();
  showToast(info.message, 'warning', 5000);
  return;
}
```

同様に `startVoiceAppend()` にも適用。

### 3. 音声 FAB の視覚的な無効化（オプション）

非対応ブラウザでは FAB をグレーアウトする:
```javascript
// init() 内
const info = getSpeechSupportInfo();
if (!info.supported) {
  voiceFab.style.opacity = '0.5';
  voiceFab.title = info.message;
}
```

## 受入条件

- [ ] Chrome/Edge でこれまでと同じく正常動作すること
- [ ] Firefox でマイクボタンタップ時にブラウザ名入りのエラーメッセージが表示されること
- [ ] 非対応ブラウザで FAB がグレーアウトされること（オプション）

## テスト方針

- Chrome で正常動作を確認
- Firefox でエラーメッセージを確認（Firefox DevTools で確認）
- UA スプーフィングで Safari のメッセージを確認

## 依存関係

- なし（独立して実装可能）

## 注意事項

- UA sniffing は非推奨だが、Web Speech API の実装状況がブラウザごとに大きく異なる現状では、ユーザーフレンドリーなメッセージのために許容される。
- Feature detection（`window.SpeechRecognition || window.webkitSpeechRecognition`）を主とし、UA sniffing はメッセージのカスタマイズのみに使用する。
